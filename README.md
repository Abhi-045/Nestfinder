🏡 NestFinder — Premium Real Estate Platform

A modern and responsive real estate web application designed for discovering, comparing, and exploring premium properties across India.
Built with HTML, CSS, and Vanilla JavaScript, featuring luxury UI design, advanced filtering, AI-inspired property insights, and interactive user experience.

✨ Features
🔍 Smart Property Search
🏘️ Featured & Recent Listings
📍 Interactive Map View
📊 AI Price Insights Section
❤️ Favorite Properties System
⚖️ Property Comparison
🏦 EMI & ROI Calculator
🎨 Luxury Dark UI with Gold Theme
📱 Fully Responsive Design
🧭 Smooth Navigation & Animations
🏢 Multi-City Property Database
🔐 Verified Listings & Premium Tags


🛠️ Tech Stack
HTML5
CSS3
JavaScript (Vanilla JS)


NestFinder/
│
├── index.html       # Main HTML Structure
├── styles.css       # Complete Styling & Responsive Design
├── app.js           # Application Logic & UI Controllers
├── data.js          # Property Database & Data Layer
│
└── README.md
